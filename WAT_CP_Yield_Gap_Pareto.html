WAT / CP Yield Gap 因子分析

資料期間 2025-12 ~ 2026-10 ｜ 配對 Lot 數 4,573（WAT Summary × CP Daily Report）

98.12%平均 WAT Yield
96.19%平均 CP Yield
1.93%平均 Yield Gap

Gap = WAT − CP = CP 總損失 3.81% − WAT 損失 1.88%。CP 損失可完整拆成各 fail bin（誤差 <0.005%），因此 gap 的因子可以用精確的數學拆解，再與機種、機台、時間、WAT 電性參數交叉驗證。

  • 重點結論：VZ0、IR0、DIR0 三個 bin 合計占 CP 損失約 91%
  • Gap 主要差異來自機種（Part No / 50A vs 35A）與時間，EPI、BGBM 影響極小
  • Gap 變異有 52% 來自 WAT 自身損失的反向抵銷

① CP Fail Bin 損失柏拉圖

各 bin 損失 % of Total in（全部 Lot Die 加權）

VZ0 1.24% + IR0 1.09% + DIR0 1.04% = 91.1% 的 CP 損失；VF0、IR2_1、VF1 為次要項。

② Gap 變異貢獻柏拉圖（精確拆解）

貢獻 % = Cov(分量, Gap) / Var(Gap)，全部分量加總 = 100%（柏拉圖取絕對值，WAT loss 為反向）

WAT loss 一項即占 51.7%（反向：WAT 損失越高，gap 越小甚至為負）；正向驅動依序為 IR0 15.0%、VZ0 12.8%、DIR0 9.2%、VF0 6.8%。

③ 影響 Gap 的因子柏拉圖

單因子解釋 Gap 變異 R²/η²（%），去除 Gap 極端值 1%–99%；顏色：■機種/材料 ■時間 ■WAT 電性 ■CP 機台/環境

因子彼此相關（機種、Type A、Die 數幾乎同源），解釋力不可相加。以 Gradient Boosting 多因子交叉驗證（測試集 R²≈0.50）：Type A 最重要，其次為時間、WAT IR(22V)、CP 溫度、BVR(5mA)、Station；EPI / BGBM 無貢獻。

  1. 優先改善 VZ0、IR0、DIR0：50A 機種 VZ0 為主，15U/13U/07U 看 IR0。
  2. 釐清 2026-04 IR0↔DIR0 消長與 2026-09 gap 回升的原因（規格／探針卡／製程變更）。
  3. 同機種下比對 ATE-2101 / 1003 / 322 的 bin 分佈，排除機種混雜。
  4. WAT 低良率 Lot 單獨管理（反向影響 gap，勿混入平均）。
